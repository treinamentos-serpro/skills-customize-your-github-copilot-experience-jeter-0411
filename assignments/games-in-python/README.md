
# 📘 Atividade: Jogo da Forca em Python

## 🎯 Objetivo

Pratique manipulação de strings, loops, condicionais, entrada de dados e seleção aleatória ao construir um jogo da Forca em Python.

## 📝 Tarefas

### 🛠️ Implementar os palpites e o progresso da palavra

#### Descrição
Crie a dinâmica principal do jogo: selecione aleatoriamente uma palavra de uma lista predefinida e permita que o jogador tente adivinhá-la, uma letra por vez.

#### Requisitos
O programa concluído deve:

- Selecionar uma palavra aleatoriamente de uma lista predefinida.
- Aceitar palpites de letras do jogador.
- Exibir as letras descobertas e ocultar as demais, usando um formato como `_ _ _`.

### 🛠️ Controlar as tentativas e o encerramento do jogo

#### Descrição
Gerencie as tentativas incorretas e encerre a partida quando o jogador adivinhar a palavra ou não tiver mais tentativas disponíveis.

#### Requisitos
O programa concluído deve:

- Rastrear e exibir o número de tentativas incorretas restantes.
- Encerrar a partida quando a palavra for adivinhada ou as tentativas se esgotarem.
- Exibir uma mensagem de vitória ou derrota ao final da partida.
